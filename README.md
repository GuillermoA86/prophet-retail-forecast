# Retail Company Forecasting & Decision Support System

Solución integral de Ciencia de Datos para la predicción de ventas, unidades y transacciones en tiendas de retail en México.

## 🚀 Requisitos previos
- Docker y Docker Compose instalados en tu equipo.

## 🛠️ Cómo correr el proyecto localmente

1. Clona este repositorio y coloca los archivos de datos (`transactions.csv`, `stores.csv`, `calendar.csv`, `data_dictionary.md`) dentro de la carpeta `data/`.
2. Levanta los servicios con Docker Compose:
   ```bash
   docker-compose up --build
